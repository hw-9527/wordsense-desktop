# 词境 WordSense · 语境词典浏览器插件

一个帮你“读懂语境”的浏览器插件：在网页上选中单词、固定搭配或习语，它会结合所在句子判断这个词在**这个语境下**的确切含义，而不是把词典里的所有意思堆给你。

## 它解决了什么问题

- 欧陆词典只能给出单词的多个释义，无法告诉你“在这个句子里到底是哪个意思” → 词境结合上下文给出**语境中的确切含义**
- 遇到 `take ... for granted`、`break the ice` 这类固定搭配 / 习语时无从下手 → 选中单个词也能自动识别它所属的搭配或习语，并解释整体含义
- 顺手补充词性、音标、其他常见含义、常用搭配、例句和中文翻译，支持朗读和复制

## 功能一览

- 选中文本后出现“词境”浮动按钮，点击即查
- 右键菜单：选中后右键 → 「用词境理解选中内容」
- 快捷键：`Alt + W` 查询当前选区
- 自动识别单词所属的固定搭配 / 习语（可在设置中关闭）
- 结果面板：类型标签（单词 / 固定搭配 / 习语）、音标、词性、语境含义、其他含义、搭配、例句、用法提示
- 朗读例句、一键复制查询结果
- 单词发音：浏览器合成发音（免费）+ 有道词典真人发音（美音），有道失败自动退回浏览器发音
- 结果面板可按住标题栏拖动到任意位置，不会被自动更新弹回
- 速度优化：常用词秒回释义（本地缓存），后台再结合语境精读更新；默认使用最快的轻量模型
- 结果缓存 7 天，同样的词和上下文不会重复扣费
- 深色模式适配

## 安装步骤（Chrome / Edge）

1. 打开浏览器扩展管理页：
   - Chrome 地址栏输入 `chrome://extensions`
   - Edge 地址栏输入 `edge://extensions`
2. 打开右上角的「开发者模式」开关。
3. 点击「加载已解压的扩展程序」。
4. 选择本文件夹（`wordsense-extension`）。
5. 安装完成后，点击工具栏里的“词境”图标，填写配置（见下）。

> 首次加载时浏览器会提示扩展可读取和更改所有网站的数据，这是因为它需要读取你选中的文字，并调用你配置的 AI 接口。个人使用请放心。

## 配置说明

打开扩展的弹窗（或右键扩展图标 → 选项），填写：

| 配置项 | 说明 |
| --- | --- |
| API 地址 | 你使用的 AI 服务地址，默认 `https://api.openai.com/v1` |
| API Key | 服务商提供的密钥，只保存在本机浏览器中 |
| 模型 | 模型名称，默认 `gpt-4.1-nano`（最快、最便宜，适合查词） |
| 温度 | 回答随机性，查词建议保持 0.1–0.3 |
| 最大输出 | 单次回答的最大 token 数，默认 1200 |
| 自动识别搭配/习语 | 查单词时同时分析它所在的固定搭配 / 习语 |
| 默认关闭思考模式 | 默认开启：自动发送 `thinking: disabled`，让 DeepSeek、智谱、Kimi 等支持该参数的服务保持快速查词；OpenAI 官方接口不发送该参数 |

填好后点「保存设置」，再点「测试连接」确认可用。

### 常用服务商配置参考

| 服务商 | API 地址 | 模型示例 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | `gpt-4.1-nano` |
| DeepSeek | `https://api.deepseek.com` | `deepseek-v4-flash`（插件自动关闭思考模式） |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| Kimi (Moonshot) | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| Ollama 本地 | `http://localhost:11434/v1` | 本地已安装的模型 |

插件会自动在 API 地址后面补上 `/chat/completions`，所有兼容 OpenAI 格式的服务都可以用。

## 使用方法

1. 在任意网页上用鼠标**选中**一个单词或短语（也可以双击选中单词）。
2. 点击出现的蓝色「词境」浮动按钮。
3. 稍等几秒，结果面板会显示：
   - 类型标签：单词 / 固定搭配 / 习语
   - 词性和音标
   - **在此语境中的确切含义**（中文 + 英文释义）
   - 如果选中的是单词，还会显示它所属的搭配 / 习语
   - 其他常见含义、常用搭配、带翻译的例句、用法提示
4. 面板底部可以**朗读**例句或**复制**查询结果；按 `Esc` 关闭面板。
5. 面板顶部的音标旁有两个小按钮：**🔊** 浏览器发音、**有** 有道词典发音（美音），点击即可朗读当前单词；有道发音不可用时会自动改用浏览器发音。

也可以选中后直接右键 → 「用词境理解选中内容」，或按 `Alt + W`。

## 常见问题

**点击后提示“尚未配置 API Key”**
说明还没填写配置。点击面板里的「打开设置」，填入 API 地址和 Key，保存后重试。

**提示无法连接**
检查 API 地址是否正确、网络是否能访问该服务（部分境外服务需要代理），也可以用「测试连接」排查。

**提示“API 返回中缺少回答内容”**
通常是模型把输出用在了推理上、「最大输出」太小导致回答被截断，或服务商临时异常。DeepSeek 用户请在设置里把模型换成 `deepseek-v4-flash`（插件检测到该模型时会自动关闭思考模式），并把「最大输出」调到 1000 以上再试；如果仍不行，检查模型名称是否与该服务商匹配。

**提示“AI 返回的内容无法解析为结果”**
插件会自动用严格模式重试一次。若反复出现，通常是「最大输出」太小导致 JSON 被截断，或模型不擅长按格式输出。请把「最大输出」调到 1500 左右、改用 `deepseek-v4-flash` / `qwen-plus` 这类文本模型（DeepSeek 的思考模式会被插件自动关闭），再点面板里的「查看原始返回」核对输出内容。

**感觉还是慢，怎么更快**
- 确认模型已换成 `gpt-4.1-nano`（或 DeepSeek、通义等国内服务，延迟更低）
- 在设置里关闭「自动识别固定搭配 / 习语」，减少分析内容
- 同一词再次出现时会直接用本地缓存秒回，无需等待
- 降低「最大输出」到 500 左右，回答更快

**在 PDF 或本地 HTML 文件里不生效**
插件默认只在 `http://` 和 `https://` 网页上运行。本地文件需要在扩展详情页里打开「允许访问文件网址」，并且 PDF 阅读器（如浏览器内置 PDF）不支持网页脚本，无法使用。

**隐私说明**
你选中的文字和它所在的句子会被发送到你配置的 AI 服务商进行理解，请选择你信任的服务。API Key 只保存在本机浏览器中，不会发送给第三方。

├── content.js         # 网页端：选词、浮动按钮、结果面板
├── lib/core.js        # 核心逻辑：提示词构建、结果解析
├── popup/             # 设置界面
├── icons/             # 扩展图标
└── README.md          # 本说明
